# Twitter Claim Lab

Small, documented tests of AI tools and ideas found in public posts on X. Each experiment starts with a specific claim and records what happened, including failures and limitations.

## Experiments

| Idea | Status | Proposed test |
| --- | --- | --- |
| [Agent memory in Markdown](experiments/agent-memory/README.md) | Planned | Compare project-question accuracy with and without a small memory index. |
| [Video reconstruction](experiments/video-reconstruction/README.md) | Planned | Compare shot detection and reconstruction on the same short video. |
| [Claude Code Projects](experiments/claude-code-projects/README.md) | Planned | Try a small parallel coding task and record setup, results, and effort. |

These are test plans, not completed benchmarks. No performance result is claimed yet.

## How experiments work

Each experiment links to the original post, describes the claim in its own words, and defines a manageable test. Completed runs should include the date, versions, inputs, commands or prompts, cost where known, raw observations, and an assessment of what the result does and does not show. Record failed runs too. Avoid publishing private data, credentials, or material without permission.

Tools and models change. A result applies to the version, settings, and input used for that run; it is not a universal ranking. A single example can expose a problem or suggest an avenue for further testing, but it cannot establish a general performance claim.
