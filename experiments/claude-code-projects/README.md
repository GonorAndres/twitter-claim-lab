# Claude Code Projects

Status: planned. No test has been run.

## Source and claim

[Lydia Hallie's post](https://x.com/lydiahallie/status/2118863157569737109) suggests using Claude Code Projects for many workflows associated with Conductor, including working from pushed branches. The post notes that multiplayer is not yet available.

## Proposed test

Use a disposable repository with two independent, well-defined coding tasks and existing checks. Record plan and account requirements, project setup, instructions, model, and whether branches must be pushed. Ask the project to coordinate the tasks and inspect the resulting branches, diffs, and test results.

Compare the hands-on time and outcome with completing the same tasks in separate ordinary sessions. Note differences in supervision, isolation, and merging. A small trial measures fit for this workflow, not feature parity with Conductor.
