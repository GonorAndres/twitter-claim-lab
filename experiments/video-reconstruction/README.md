# Video analysis and reconstruction

Status: planned. No test has been run.

## Source and claim

[Miao Yang's post](https://x.com/WaterrrMiao/status/2118790987875221905) compares reverse-any-video and REA-Video on video analysis and reconstruction. The reported results come from a person presenting one of the compared tools; this experiment will not treat those numbers as independent verification.

Sources: [HyperFrames documentation](https://github.com/heygen-com/hyperframes/blob/main/docs/packages/cli.mdx) and [REA-Video repository](https://github.com/JuneYaooo/rea-video).

## Proposed test

Choose one short video with permission to analyze and recreate it. Manually mark shot boundaries before running either tool. Record versions, machine, model, settings, setup time, account requirements, and any charges. Run each tool with equivalent inputs where possible.

Compare detected shots against the manual labels, with a stated timing tolerance. Review the practical usefulness of each analysis and reconstruction, and record runtime and cost. Keep outputs or links where sharing is permitted. Report setup or access failures rather than silently omitting them.

One video can reveal practical differences, but cannot validate broad claims about accuracy or speed across video styles.
